# Cafeteria Website

A lightweight, purely frontend web application for a cafeteria. This project provides a user-friendly interface to browse a food menu, manage a shopping cart, and submit mock orders and feedback using local storage and vanilla JavaScript.

## Features

- **Home Page**: A welcoming landing page (`index.html`).
- **Interactive Menu**: Browse various food items including burgers, pizza, coffee, momos, noodles, shakes, and cupcakes (`menu.html`). Includes category filtering and real-time search capabilities.
- **Shopping Cart**: View and manage selected items (`cart.html`). Uses browser `localStorage` to persist cart data across pages.
- **Order Form**: A form to submit customer feedback with a visual 5-star rating system (`form.html`).
- **Completely Static**: Operates entirely within the browser without the need for a backend server or database.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## Getting Started

To view and interact with this project locally:

1. Clone or download the project files to your local machine.
2. Open the `index.html` file directly in your preferred web browser. No local server or build tools are required!
3. Use the navigation links to explore the menu, add items to your cart, and view the feedback form.

## Project Structure

- `*.html` - Core structure and pages of the frontend application.
- `style.css` - Custom stylesheet for the application's design, using CSS variables and modern layout techniques.
- `script.js` - Client-side logic, cart management via `localStorage`, and interactivity.
- `*.jpg` - Image assets for the food items and background.
